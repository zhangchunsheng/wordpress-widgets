嵌入每日英语句子到 WordPress

使用 iframe 方式在 WordPress 侧边栏或小工具区域展示爱词霸每日英语句子

快速开始

复制以下代码，粘贴到 WordPress 的「自定义 HTML」小工具中：

<iframe width="280" height="300" src="https://www.luomor.com/daily_english.html" frameborder="0"></iframe>

在 WordPress 中添加步骤

  1. 登录 WordPress 后台 — 进入您的网站管理面板
  2. 外观 → 小工具 — 找到侧边栏或页脚小工具区域
  3. 添加「自定义 HTML」小工具 — 点击 + 号，搜索「HTML」
  4. 粘贴代码 — 将上方 iframe 代码粘贴到内容框
  5. 保存 — 点击「保存」按钮，完成！

尺寸调整

根据您的侧边栏宽度，可以调整 iframe 的尺寸：

场景 宽度 高度 代码
窄侧边栏 240px 320px width="240" height="320"
标准侧边栏 280px 300px width="280" height="300"
宽侧边栏 320px 280px width="320" height="280"
内容区域 100% 300px style="width:100%;height:300px"
提示：使用 style="width:100%" 可以让 iframe 自适应容器宽度，推荐在响应式主题中使用。

自适应宽度版本

<iframe style="width:100%;min-width:240px;height:300px" src="https://www.luomor.com/daily_english.html" frameborder="0"></iframe>

注意事项

  • 确保您的 WordPress 主题允许在小工具中使用 iframe（大多数主题都支持）
  • 如果 iframe 不显示，检查主题是否有限制 iframe 的安全设置
  • 建议在小工具标题中不要重复「每日英语」等文字，保持简洁
  • 如需修改样式，请下载 HTML 文件后自行托管
